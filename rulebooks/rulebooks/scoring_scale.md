# Scoring Scale
Last Updated: 2026-02-24

## Rating Scale
1 = Off Track  
2 = Effective  
3 = Outstanding  

## Overall Rating Bands
1.00–1.99 = Off Track  
2.00–2.66 = Effective  
2.67–3.00 = Outstanding  

## Scoring Rules
- Only score criteria defined as “Scored” in the rulebook.
- Any “Critical but Not Scored” criteria must be reported but excluded from averages.
- Manual Verification Required does not count as Pass or Fail; it is a separate state.
