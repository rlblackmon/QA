# Shared Definitions
Last Updated: 2026-02-24

## Evidence Rules
- Evidence must be quoted or clearly referenced from the provided input.
- If evidence is missing or unclear: mark **Manual Verification Required**.
- Never infer actions that are not explicitly documented.

## Result Labels
- ✅ Pass
- ❌ Fail
- 🔶 Manual Verification Required

## Common Fields
- Criterion
- Result
- Evidence
- Notes (optional)
